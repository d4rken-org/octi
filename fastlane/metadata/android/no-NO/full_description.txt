<i>Octi</i> viser deg hva som skjer på dine andre Android-enheter.

Sjekk batteristatusen på nettbrettet ditt uten å reise deg. Kopier på telefonen, lim inn på nettbrettet. Få en varsel når batteriet på den andre telefonen blir lavt.

<b>Hva Octi kan gjøre:</b>

* Batterinivå og ladestatus for hver enhet
* WiFi- og nettverksstatus på et øyeblikk
* Utklippstavle-synkronisering: kopier på en enhet, lim inn på en annen
* Send filer mellom enhetene dine
* Se hvilke apper som er installert på dine andre enheter
* Batterivarslinger for dine andre enheter
* Startsidewidgeter for batteri, nettverk og utklippstavle
* Enhetsdetaljer: modell, Android-versjon, oppetid og mer

<b>Slik fungerer det:</b>

Installer Octi på to eller flere enheter og koble dem sammen på minutter:

* Google Drive – logg inn med samme konto på hver enhet, ferdig
* Octi Server – gratis og anonym, ingen konto kreves; enheter kobles sammen via QR-kode og data er kryptert ende til ende, bare dine enheter kan lese det
* Kjør din egen Octi Server (åpen kildekode)

Synkalternativer kan kombineres fritt.

<b>Personvern først:</b>

* Åpen kildekode
* Ingen annonser, ingen sporing, ingen data solgt
* Ingen konto eller e-post kreves

Octi er gratis. Et valgfritt kjøp i appen låser opp noen ekstra funksjoner og støtter utvikling.
